The decor axis lands on `Form`: `size` cascades the control width in the
leaf word list (`xs | sm | md | lg`) but stays a state class — it is
injected only into controls that declared no own `size`, and the control's
word wins (no lock, unlike `disabled`). `colon` appends the `：` to every
label for the Chinese admin-form habit, painted as a decoupled piece so the
label's text and queryable name stay the author's words; a field opts out
per field. Preview story, docs page and wiki module updated in lockstep.
