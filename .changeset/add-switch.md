Add Switch: single boolean toggle on the Checkbox row contract — a native
checkbox input (`role="switch"`, name/value and the change event untouched)
dressed as a track with a sliding thumb; `children` render as the label;
four size tiers (xs/sm/md/lg on the shared row-height scale); a `palette`
axis coloring the ON state from the six Button families (brand by default)
while the off state keeps the neutral fabric; `invalid`/`disabled` states;
per-subpath entry `@colox/react/switch`, preview stories and a docs page;
wiki component map updated in lockstep.
