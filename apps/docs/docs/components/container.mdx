# Container

`Container` is the semantic width shell: it caps content to a design-token width
ceiling, centers it and pads it inline. Everything else belongs to the layout mechanisms
(`Stack`, future `Grid` and `Positioner`); `Container` only owns the page-width
semantic — no flexbox, no grid, no positioning.

## Size

`size` caps the width with a large-dimension design token: `sm`/`md`/`lg`/`xl` =
640/768/1024/1280px (`--colox-size-160/192/256/320` from the Figma size language).
Breakpoints stay where they belong — responsive logic — and never leak into width.
Without a `size` prop the container keeps the CSS default: no cap, filling its parent.

<Container size="md">
  <div className="container-demo">size md — 768px cap, centered</div>
</Container>

```mdx
<Container size="md">…</Container>
```

Each size references the design token directly (`--colox-size-*`, single-sourced in
the theme), never a hard-coded value.

## Gutter

`gutter` sets the inline padding from the spacing scale (`--colox-spacing-*`: 4px steps
with 2px half steps). Without a `gutter` prop the container inherits the CSS-default
padding of `0`.

```mdx
<Container size="md" gutter="4">
  …
</Container>
```

## Alignment

`align` places the constrained box on the inline axis, in the box-alignment
vocabulary (`start`/`center`/`end` — same words as CSS `align-self`; no
physical `left`/`right`, so RTL text flows mirror correctly). Centering is the
shell semantic — the default — and `start`/`end` pin the box to either edge of
its parent.

```mdx
<Container size="md" align="end">
  …
</Container>
```

## Props

| Prop   | Type                                        | Default    | Notes                 |
| ------ | ------------------------------------------- | ---------- | --------------------- |
| size   | `'sm' \| 'md' \| 'lg' \| 'xl'`              | —          | max-inline-size cap   |
| gutter | spacing key (`'1'`…`'16'`, `'0-5'`…`'4-5'`) | —          | padding-inline: 0     |
| align  | `'center' \| 'start' \| 'end'`              | `'center'` | inline-axis placement |

`Container` accepts all native `<div>` attributes and forwards refs. It is fully
static: it reads no theme context at runtime, so it renders meaningfully without a
`<ColoxTheme>` provider.
