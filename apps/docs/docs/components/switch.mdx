# Switch

Switches toggle a single boolean — settings, feature flags, consent. The same
row contract as Checkbox: a native `<input type="checkbox" role="switch">`
carries the form value, the keyboard and the events; the track and the sliding
thumb are the visual dress. `children` render as the label.

## Sizes

<Switch size="xs">Extra small</Switch>

The four tiers share the Button/Input/Checkbox row heights (24/32/40/48) and
font scale, so switch rows sit flush next to same-tier controls.

## Palette

`palette` colors the ON state from the six Button families — primary (brand),
gray, info (blue), error (red), warning (orange), success (green). The off
state keeps the neutral fabric and `invalid` keeps the red channel.

## Controlled and uncontrolled

Like Checkbox, the switch reads `checked` for controlled use and
`defaultChecked` for the initial state of an uncontrolled one — the change
event stays the native one, the new value on `event.target.checked`.

<Switch defaultChecked>Starts on (uncontrolled)</Switch>

the browser's form data untouched.
