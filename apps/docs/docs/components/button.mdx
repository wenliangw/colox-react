# Button

Buttons trigger user actions.

## Variants

<Button variant="primary">Primary</Button> <Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button> <Button variant="danger">Danger</Button>

## Sizes

<Button size="sm">Small</Button> <Button size="md">Medium</Button> <Button size="lg">Large</Button>

## Loading

<Button loading>Loading</Button>

## Props

| Prop    | Type                                              | Default     |
| ------- | ------------------------------------------------- | ----------- |
| variant | `'primary' \| 'secondary' \| 'ghost' \| 'danger'` | `'primary'` |
| size    | `'sm' \| 'md' \| 'lg'`                            | `'md'`      |
| loading | `boolean`                                         | `false`     |

It also accepts all native `<button>` attributes.
