# Compact

`Compact` is the visual joining base: it seams sibling members into one unit —
shared borders, radii only at the group's two ends, and a focus ring that
breathes across junctions. It is deliberately **wordless**: no gap, no
alignment, no direction — spacing and layout stay with [`Stack`](./stack),
the seam stays here.

Every member keeps its own value, state and `{ event, value }` payload.
`Compact` never speaks for them.

## Segments

Several inputs joined as one unit — each still holds its own value, so in a
form each segment rides its own `Form.Field`. Sized, the members split the
width evenly; left bare, the group hugs their contents:

<Compact style={{ width: 320 }}>
  <Input aria-label="segment 1" placeholder="seg 1" />
  <Input aria-label="segment 2" placeholder="seg 2" />
  <Input aria-label="segment 3" placeholder="seg 3" />
  <Input aria-label="segment 4" placeholder="seg 4" />
</Compact>

```mdx
<Compact style={{ width: 320 }}>
  <Input placeholder="seg 1" />
  <Input placeholder="seg 2" />
  <Input placeholder="seg 3" />
  <Input placeholder="seg 4" />
</Compact>
```

## Action member

A button that joins visually but keeps its own click — the search / captcha
recipe:

<Compact>
  <Input placeholder="Search…" style={{ width: 220 }} />
  <Button>Search</Button>
</Compact>

```mdx
<Compact>
  <Input placeholder="Search…" style={{ width: 220 }} />
  <Button>Search</Button>
</Compact>
```

## Addons

Non-control members (¥ prefix, unit suffix) ride the
`colox-compact__addon` class: a segment look that produces no value.

<Compact>
  <span className="colox-compact__addon">¥</span>
  <Input placeholder="0.00" style={{ width: 140 }} />
  <span className="colox-compact__addon">/件</span>
</Compact>

```mdx
<Compact>
  <span className="colox-compact__addon">¥</span>
  <Input placeholder="0.00" style={{ width: 140 }} />
  <span className="colox-compact__addon">/件</span>
</Compact>
```

## Mixed controls

A `Select` prefix still owns its value — the seam is purely visual:

<Compact>
  <Select style={{ width: 96 }} aria-label="区号">
    <Select.Option value="86" text="+86" />
    <Select.Option value="1" text="+1" />
  </Select>
  <Input placeholder="号码" style={{ width: 200 }} />
</Compact>

```mdx
<Compact>
  <Select style={{ width: 96 }} aria-label="区号">
    <Select.Option value="86" text="+86" />
  </Select>
  <Input placeholder="号码" style={{ width: 200 }} />
</Compact>
```

## The seam rules

- Members sit flush: a `-1px` pull collapses two 1px borders into one line
  (the pull stays in lock-step with the members' border width).
- Width: the input family splits the group — sized, they share it evenly;
  left bare, the group hugs their contents.
- Radii live only at the two ends (`--colox-radius-lg`, the members' own
  radius token). The seam owns the member shapes: inner corners are
  squared, a member's own `rounded` form squares inside a group, and a
  lone child keeps its shape untouched. Shape-keeping members (Switch,
  Slider) are exempt — their design rounds them, the seam doesn't.
- Focus belongs to the unit — for the input family: when the focus sits
  inside one of those members (or its panel is open — the `--open` class
  keeps the ring alive even though the panel's focus lives in a portal),
  one brand ring traces the whole seam (`:focus-within:has(...)` on the
  group, the end-corner radius). Inside the group a member draws no
  second layer — the input family's own ring stays silent and its border
  keeps the resting token (invalid members keep their red border).
  Buttons and their kin keep their own focus affordance: the unit ring
  does not pretend they are a text control. Button variants keep their
  own palette borders: the Compact layer never reaches into variant
  colours.
- An invalid member invalidates the unit: the whole outline reddens
  (input family + addons; buttons keep their palette), and any
  engagement inside the unit (family focus, open panel) rings it red —
  Compact reads as one control, never as loose members.
- `size` and `palette` are inherited words: `<Compact size="sm">` serves
  them to every member that carries the word, through context. The
  member's own `size`/`palette` always wins; a Form-level `size` injected
  into the control also beats the Compact default. No cloning is
  involved — members stay the author's own elements. Members without a
  palette word simply ignore it.
- `colox-compact--divide` is the divider gesture: the members drop their
  own borders, the unit draws one frame (`--colox-color-border-muted`),
  and each boundary after the first carries a short floating bar
  (a pseudo-element, `inset-block: 25%`, `--colox-color-border-subtle`)
  that never touches the frame. An invalid member reddens the frame
  and the bars together. Plain members + addons still seam with the
  classic overlapping borders when the modifier is absent.
- Elevation and press-scale belong to standalone buttons: a member's
  shadow or active scale stays quiet inside the seam.
- Logical properties throughout: the seam is RTL-safe.

## Props

`Compact` accepts the standard `HTMLAttributes<HTMLDivElement>`
(`className`, `style`, `id`, `ref`, …) plus two inherited state words:
`size` (`'xs' | 'sm' | 'md' | 'lg'`) and `palette`
(`'primary' | 'gray' | 'info' | 'error' | 'warning' | 'success'`) — both
optional, both shared as context defaults.
