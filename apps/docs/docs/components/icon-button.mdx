# IconButton

The square bare-button primitive for icon-only controls: one place for the
button reset, the token-pinned hit shape, hover/active feedback, the focus
ring and the disabled semantics. Buttons in the field controls (Input clear /
visibility toggle, Select clear / chip remove) are built on it.

An icon carries no text node, so an icon button is nameless to assistive
tech — always pass `aria-label` (or valid `aria-labelledby`).

<IconButton aria-label="Close">
  <IconX />
</IconButton>
<IconButton aria-label="Close" variant="muted">
  <IconX />
</IconButton>
<IconButton aria-label="Close" variant="outline">
  <IconX />
</IconButton>
<IconButton aria-label="Close" variant="solid">
  <IconX />
</IconButton>
<IconButton aria-label="Close" variant="solid" palette="error">
  <IconX />
</IconButton>
<IconButton aria-label="Close" disabled>
  <IconX />
</IconButton>

## Size

`size` accepts the preset form tiers (same-name same-height as
Input/Button/Select) **or any theme size-token key** — the raw key pins the
footprint to that token, so theme overrides flow through.

<IconButton aria-label="Extra small" size="xs">
  <IconX />
</IconButton>
<IconButton aria-label="Small" size="sm">
  <IconX />
</IconButton>
<IconButton aria-label="Medium" size="md">
  <IconX />
</IconButton>
<IconButton aria-label="Large" size="lg">
  <IconX />
</IconButton>

<IconButton aria-label="Icon" size="4">
  <IconEye />
</IconButton>
renders a 16px square; `size="7"` renders 28px — any `sizeKeys` value works.

## Variant & palette

`variant` is the strength ladder, and it sets the icon color, not only the
chrome: `plain` (default) is the pure icon — the box hugs the icon (`size`
sizes the icon itself) and the icon is painted in the palette color,
darkening to the palette hover/active shade; `muted` is the quiet context
tier — the same icon-hugging form, speaking at the muted text volume at
rest and the default volume on hover/active, independent of the palette;
`ghost` tints the icon with a wash on hover; `outline` carries a palette
border; `surface` a muted ring over a subtle tint; `subtle` the tint fill;
`solid` the filled paint. Filled variants swap tiers on hover/active
(`subtle/surface → muted`), unfilled ones layer a wash. `palette` is the
design-language six-family axis (primary/gray/info/error/warning/success)
— **gray by default** — it drives the icon color, the hover feedback, the
focus ring and the variant paint (except `muted`, which speaks with the
surrounding text). The ring speaks the button's own tone: a neutral control
gets a neutral ring, a semantic family keeps its color.

## Rounded

The footprint is a square with the small radius by default; `rounded`
switches it to a full circle — the hover/active wash follows the shape.

<IconButton aria-label="Rounded" rounded>
  <IconX />
</IconButton>
<IconButton aria-label="Rounded solid" rounded variant="solid">
  <IconX />
</IconButton>

## Props

| Prop    | Type                                                                             | Default   |
| ------- | -------------------------------------------------------------------------------- | --------- |
| size    | `'xs' \| 'sm' \| 'md' \| 'lg' \| SizeKey` (theme tokens)                         | `'md'`    |
| variant | `'plain' \| 'muted' \| 'ghost' \| 'outline' \| 'surface' \| 'subtle' \| 'solid'` | `'plain'` |
| palette | `'primary' \| 'gray' \| 'info' \| 'error' \| 'warning' \| 'success'`             | `'gray'`  |
| rounded | `boolean`                                                                        | `false`   |

It also accepts all native `<button>` attributes (`type` defaults to
`'button'`).
