# Loading

The **inline busy indicator**: a decorative motion figure that says
"work in progress" — it paints no value and no layout. Determinism
belongs to `Progress`, placeholding to `Skeleton`.
`animation` (`spinner`/`dots`/`pulse`, `spinner` by default) picks the
figure: a round arc spinning, three dots in a staggered wave, a solid
core with two filled bands rippling outward.

## Sizes

`size` (`sm` 16 / `md` 24 / `lg` 32 riding the theme size scale, or a
number pinning the exact pixel footprint) moves the **indicator only**
— the label keeps the surrounding text size.

  <Loading size="sm" />
  <Loading size="md" />
  <Loading size="lg" />
  <Loading size={40} />
</Stack>

## Label and color

`label` rides beside the indicator and doubles as the accessible name;
with neither `label` nor `aria-label`, the default name is "Loading".
The figure inherits `currentColor`, so a spinner dropped into a Button
or a tinted line of text picks the color up for free — no color axis
to tune:

<Stack direction="row" gap="16" align="center">
  <Button>提交中</Button>
  <Button variant="subtle">
    加载中 <Loading size="sm" />
  </Button>
</Stack>

The tint is a plain `color`, so any design token works — no palette axis
to learn; every `animation` inherits `currentColor` equally:

## Accessibility and motion

The root announces itself with `role="status"` (an implicit polite live
region); the animated figure is hidden from screen readers as pure
decoration. Under `prefers-reduced-motion: reduce` the motion calms
down rather than freezing — the spin turns slower, the dots sync into
one soft breath, the pulse ripples slower.

`Loading` is a **leaf**: it never wraps or masks children. To mark a
whole region as loading, compose it yourself — e.g. an absolutely
positioned `Empty`-style block carrying a centered `Loading` over the
content. That stays the caller's overlay, this stays the indicator.
