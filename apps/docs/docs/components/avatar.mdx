# Avatar

The portrait primitive — a round footprint carrying one of three content
forms in priority order:

1. **`children`** — a rich content slot (an icon or any custom node), always
   wins when present;
2. **`src`** — the picture avatar; on load failure it falls back to
   `fallback`, then to the `name` initials, then to the `alt` initials;
3. **`name`** — a person name, automatically reduced to its initials (CJK
   first character, Latin first letters).

`fallback` is the image-failure escape hatch only — a missing `src` never
shows it; `name` (then `alt`) initials are the standing text fallback.

## Shape

Circle is the default — an avatar reads as a round portrait. `rounded` rides
the form-family radius, `square` has none.

<Avatar name="张伟" shape="circle" />
<Avatar name="张伟" shape="rounded" />
<Avatar name="张伟" shape="square" />

## Size

`size` takes the preset form tiers (same-name same-block as
Input/Button/Select) **or any theme size-token key** — the text tier follows
the footprint proportionally.

<Avatar name="张伟" size="xs" />
<Avatar name="张伟" size="sm" />
<Avatar name="张伟" size="md" />
<Avatar name="张伟" size="lg" />

`size="4"` renders a 16px avatar; `size="7"` renders 28px — any `sizeKeys`
value works.

## Variant and palette

`variant` sets the surface strength of the **text avatar** (and of the
failure fallback); `palette` the semantic color family of the colored
variants. A picture avatar ignores the axis — the image is the content.

- `plain` (default): the quiet neutral portrait surface — muted background,
  default text, palette-independent.
- `subtle`: the palette tint fill.
- `solid`: the full palette fill with inverse text.
- `outline`: a palette ring on a transparent fill.

## Failure fallback

A picture avatar whose `src` fails to load fires `onError` once and falls
back to the `fallback` escape hatch when given, then to the `name`
initials, then to the `alt` initials.

<Avatar src="https://example.invalid/avatar.png" alt="张伟" name="张伟" />
<Avatar src="https://example.invalid/avatar.png" alt="张伟" fallback={<span>!</span>} />

## Accessibility

- A picture avatar reads through the inner `img`'s `alt` — required; a
  missing `alt` warns and renders an empty alt.
- The derived text avatar is `role="img"`, named by `aria-label`, then the
  `name`, then the `alt`.
- An author-supplied `children`/`fallback` node owns its own naming.
