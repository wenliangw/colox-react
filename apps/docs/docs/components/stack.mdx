# Stack

`Stack` is the flexbox layout primitive: one mechanism, semantic props that ride the theme
token grid. Spacing keys come from the theme's spacing scale (`--colox-spacing-*`: 4px
steps with 2px half steps), so stacked content always lands on the token grid and
re-themes for free.

## Main axis

`direction` sets the flex direction; `gap` sets the spacing between children.

<Stack direction="row" gap="2">
  <Button>Save</Button>
  <Button variant="outline">Cancel</Button>
</Stack>

```mdx
<Stack direction="row" gap="2">
  <Button>Save</Button>
  <Button variant="outline">Cancel</Button>
</Stack>
```

<Stack direction="column" gap="4">
  <div>First block</div>
  <div>Second block</div>
</Stack>

```mdx
<Stack direction="column" gap="4">
  <div>First block</div>
  <div>Second block</div>
</Stack>
```

## Item and the spacer semantics

`Stack.Item` participates in the layout; `grow` absorbs the free space along the main
axis, pushing the neighbours apart:

<Stack gap="2">
  <Button variant="outline">Back</Button>
  <Stack.Item grow />
  <Button>Next</Button>
</Stack>

```mdx
<Stack gap="2">
  <Button variant="outline">Back</Button>
  <Stack.Item grow />
  <Button>Next</Button>
</Stack>
```

## Responsive gap

`Stack.Responsive` is the mounted capability for per-breakpoint gap overrides. The theme
runtime publishes its breakpoint band on `<html data-colox-breakpoint>`; `Stack.Responsive`
resolves the config against the current band via the theme context and registers the
result with the enclosing `Stack`. Values apply while the viewport fits the band's
max-width cap, so narrow bands win and `base` (the widest band) is the last fallback. A
static `Stack` never touches the theme context.

```mdx
<Stack gap="4">
  <Stack.Responsive gap={{ base: '2', lg: '8' }} />
  <div>gap 8 below 1024px, gap 2 beyond</div>
  <div>and back to the static "4" if this part unmounts</div>
</Stack>
```

## Gap scale

`gap` accepts the spacing keys: `1`–`14`, `16` (16px–64px in 4px steps) and the half
steps `0-5`–`4-5` (6px–18px). Without a `gap` prop the stack inherits the CSS-default gap
of `0`.

## Props

### Stack

| Prop      | Type                                                                | Default     | Notes           |
| --------- | ------------------------------------------------------------------- | ----------- | --------------- |
| direction | `'row' \| 'column' \| 'row-reverse' \| 'column-reverse'`            | `'row'`     | flex-direction  |
| gap       | spacing key (`'1'`…`'16'`, `'0-5'`…`'4-5'`)                         | —           | gap: 0          |
| align     | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'`           | `'stretch'` | align-items     |
| justify   | `'start' \| 'center' \| 'end' \| 'between' \| 'around' \| 'evenly'` | `'start'`   | justify-content |
| wrap      | `boolean`                                                           | `false`     | flex-wrap: wrap |

### Stack.Item

| Prop | Type      | Default | Notes        |
| ---- | --------- | ------- | ------------ |
| grow | `boolean` | `false` | flex-grow: 1 |

### Stack.Responsive

| Prop | Type                                            | Notes                                        |
| ---- | ----------------------------------------------- | -------------------------------------------- |
| gap  | `{ base?, sm?, md?, lg?, xl? }` of spacing keys | resolves against the current breakpoint band |

`Stack` and `Stack.Item` accept all native `<div>` attributes and forward refs.
`Stack.Responsive` must be mounted inside a `Stack` and renders nothing itself.
