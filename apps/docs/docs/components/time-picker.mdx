# TimePicker

A single-line time editor: a bare text input in the Input family shell
plus a self-drawn panel riding the cdk popup. The panel holds three
pure-number cyclic columns — hours 00–23, minutes 00–59, seconds
00–59 — each an 8-option wheel on a natively scrolling column (the
scrollbar is hidden): the mouse wheel and the trackpad scroll the
column freely — fractional rest positions are fine and the wheel
selects nothing —, hovering a cell pre-selects it visually (a
neutral gray wash — never the palette, so the preselection can't be
mistaken for the selection — restored on leave; while the wheel
rolls the column suppresses pointer events, so cells racing under
the cursor never flash), and a click is the
selection: the picked option becomes the pending word and glides
back onto the focus slot (a rAF direct-write ride re-aligns it over
240ms — the wheel's own scrollTop write channel, so the offset and
the rendered window can never disagree for a painted frame — instant
under the motion gate). The up/down chevrons ride the same
direct-write ±7-option step, and the glide keeps the clicked
direction across the cycle seam — 23 → 00 scrolls down (the ±one-lap
wrap is folded into every frame-write, so each write stays inside
the band, the seam crossing is a content-identical reset inside the
ride, and nothing can flash) instead of re-entering the band
backwards; the chevrons are throttled by the ride's own
duration — clicks during the glide are dropped, the steppers gray
(the family's disabled-text shade) while the gate stands, and the
next one lands only after the ride ends. The selection wash rides the value,
so it scrolls with its cell. Picks don't commit straight away — they
preview into the field in gray placeholder styling and the pending
option wears the palette subtle; the panel's confirm button (确定 by
default, text via `confirmText`) commits
the word, closes and refocuses the field, while Escape or an outside
click discards the pick. The canonical value is the fixed-width
`HH:mm:ss` word; `null` is the empty state.

```tsx
import { TimePicker } from '@colox/react';
```

## When to use

- Any field that collects a time-of-day — schedules, alarms, working
  hours.
- When typed entry and picking should both work: the panel selects,
  keystrokes parse and normalize the same `HH:mm:ss` word.
- When a time bound (`min`/`max`) must disable out-of-range options
  instead of leaving invalid picks to a form layer.

## Examples

### Basic

Typing takes the canonical `HH:mm:ss` grammar and the lenient `H:m`
spelling (`8:30` and `8:3` rhyme, a missing second defaults to `00`);
a complete word commits at once. Picking is two-step: open the panel
and wheel-click through the columns — the field previews the tentative
word in gray — then the confirm button (确定, see the API table below) commits
it. The wheel seats the committed
value at slot 4 (three options above, four below) and the system clock
when the field is empty: an empty open pre-selects the clock — the
subtle wash rides it and the confirm button commits it straight away;
the pending option wears the palette subtle.

## Value formats

`valueFormat` renders the field text with the standard clock-pattern
tokens: `H`/`HH`, `h`/`hh`, `m`/`mm` and `s`/`ss` — single letters
skip the zero pad, doubled letters pad to two digits, and every other
character is a literal separator. The internal value and the change
payload stay canonical `HH:mm:ss` regardless of the format.

<TimePicker aria-label="Zero-padded 24-hour" defaultValue="08:30:15" />

<TimePicker aria-label="Single-digit clock" valueFormat="H:m:s" defaultValue="08:30:15" />

<TimePicker aria-label="Twelve-hour clock" valueFormat="h:mm:ss" defaultValue="13:30:15" />

<TimePicker aria-label="Dotted separators" valueFormat="H.mm.ss" defaultValue="08:30:15" />

Hours stay the factual clock hour — there is no meridiem token in the
pattern vocabulary; the display format never leaks into the value.

## Bounds

`min`/`max` accept strings or `Date`s (read at local wall-clock time)
and are editor mechanics, not a validation layer: an option is
disabled when the word picking it would produce falls out of bounds —
each option compares its merge with the pending word, so a click can
never land an out-of-range word. The wheel can roll a column onto a
disabled range; while the pending word sits out of bounds the confirm
button disables, and no commit path can fire it. A typed out-of-range
value holds silently until blur rolls it back. Times have no honest
"nearest legal value", so rollback — not clamping — is the mechanism.

<TimePicker aria-label="Working hours" min="09:00:00" max="18:00:00" defaultValue="13:30:15" />

## Clearable

`clearable` follows the Select interaction: with a committed value,
hovering or focusing the field swaps the trailing clock glyph for the
✕ clear control — clicking it commits `null` through the change
payload and returns focus to the field.

## Keyboard

- **Field**: ArrowDown / Enter opens the panel; Escape closes it.
- **Column**: ↑/↓ move the pending option one step (the track scrolls
  to follow); PageUp/PageDown ride the smooth 7-option step; Home/End
  land the column bounds (00 / 23, 00 / 59); ←/→ swap columns;
  Enter/Space pick the focused option as the pending word.
- **Confirm**: the panel's confirm button — or Tab to it and Enter —
  commits the pending word, closes the panel and returns focus to the
  field. Escape and outside clicks discard the pending pick.

## API

| Prop           | Type                                                                 | Default      | Notes                                                                |
| -------------- | -------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------- |
| `value`        | `string \| null`                                                     | —            | Canonical `HH:mm:ss`; controlled when set.                           |
| `defaultValue` | `string \| null`                                                     | `null`       | Uncontrolled seed.                                                   |
| `valueFormat`  | `string`                                                             | `'HH:mm:ss'` | Display pattern; also the placeholder.                               |
| `min` / `max`  | `string \| Date`                                                     | —            | Time bounds at local wall-clock time; out-of-range options disable.  |
| `palette`      | `'primary' \| 'gray' \| 'info' \| 'error' \| 'warning' \| 'success'` | `'primary'`  | Colors the selection semantics only.                                 |
| `size`         | `'xs' \| 'sm' \| 'md' \| 'lg'`                                       | `'md'`       | Family row heights (24/32/40/48).                                    |
| `clearable`    | `boolean`                                                            | `false`      | Select-style trailing ✕ control.                                     |
| `confirmText`  | `string`                                                             | `'确定'`     | The panel footer's confirm button text.                              |
| `invalid`      | `boolean`                                                            | `false`      | Red border/ring + `aria-invalid`.                                    |
| `open`         | `boolean`                                                            | —            | Controlled panel visibility; `defaultOpen` seeds it.                 |
| `onChange`     | `(payload: { event; value }) => void`                                | —            | `value` is the canonical `HH:mm:ss` string or `null` (commits only). |
| `onOpenChange` | `(open: boolean) => void`                                            | —            | Fires when the panel opens/closes.                                   |
