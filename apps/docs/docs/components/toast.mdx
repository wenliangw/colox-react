# Toast

The **lightweight hint face** of the message system — the antd-message
tier. A slim single-line pill (`bg-default`, the Popover surface) with
a palette tone icon, the body words and a close button. No title, no
action — those are the Notify tier's job.

The message system is two pieces: one **container** per scope (a
`<MessageViewport>` you mount), and the **imperative faces** that route
into it (`Toast.…` / `Notify.…`). Both faces share one scope table, so
a single container holds toast and notify entries side by side.

## Container

Mount one `<MessageViewport>` per container. The default `scope`
(`'root'`) is the screen-wide container every unscoped call routes into
— `positioning="fixed"` pins it to the viewport:

```tsx
<MessageViewport />
```

A scoped container (`scope="panel"`, `positioning="absolute"`) pins
itself inside a `position: relative` parent — a panel, a card, a
drawer. Messages sent with `{ scope: 'panel' }` land inside that box:

```tsx
<div style={{ position: 'relative', height: 240 }}>
  <MessageViewport scope="panel" positioning="absolute" />
</div>;

Toast.info('Inside the panel.', { scope: 'panel' });
```

## The imperative API

`Toast.…` is a global namespace — call it from anywhere (a click
handler, a fetch callback, a store action). Tone shortcuts:

```tsx
Toast.info('Saved.');
Toast.success('All good.');
Toast.warning('Heads up.');
Toast.error('Something went wrong.');
```

The return value is the message's id — hand it to `Toast.dismiss(id)`.
`Toast.custom(anyNode)` renders arbitrary React content as-is (a
progress bar, a live status). Options: `scope`, `position` (default
`top-center`), `duration`, `key`.

## Lifecycle

- **Duration**: auto-dismiss after 3s by default; `duration: 0` is
  sticky (only the close button dismisses). Hovering a toast pauses its
  countdown.
- **Close**: the corner close button (IconButton muted), or
  `Toast.dismiss(id)` / `Toast.dismiss()` (all in the scope).
- **Update**: `Toast.update(key, patch)` mutates a live toast in place —
  progress, retries. Give the toast a `key` to target it.
- **Exit**: each toast plays its own exit animation before the store
  removes it.

## Surface

Opaque `bg-default` pills (the Popover surface — translucency is the
hover-hint Tooltip recipe, and a toast never hovers) with a union
drop-shadow, radius-lg, no border. The palette tone drives the semantic
icon (info/success/warning/error) tinted by the design-language text
tokens. `role="status"` (polite) announces each toast.
