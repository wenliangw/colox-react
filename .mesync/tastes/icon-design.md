# 图标设计规范

图标是设计语言「看得到的那张脸」——库必须自己拥有基础图形集（用户定调），SVG 组件源是唯一形态（icon font 死在 stroke 度量上）。规范本身是**契约**，机器门禁是执行。

- **包边界**：第一方基础图标独立包 `@colox/icons`；组件内置态与消费方共用同一源（不是私藏拷贝）；插槽仍收 ReactNode——基础成语用本包、业务图形自备，两条路并存而非二选一。
- **度量锚在做换算**：24 viewBox / stroke 1.5 / round cap+join / currentColor / 1em。每一条都有几何理由，不是风格自嗨——1.5@24 在 16px 渲染恰等效 1px（组件边框同频）、currentColor 继承语义色、1em 继承字号（token 体系流经宿主）。
- **圆角挂 token 家族**：直角弯 r=2（radii.xs）、大弧 r=4（radii.sm）——形语言事实与组件共享，不发明新值。
- **整数网格 + [2,22] 光学内容框**：节点全整数（亚像素锐利）、笔画含 bleed 不越内容框（与文字并排行高不打架）。
- **成对同源**：chevron 四向 = 一张 d 旋转 0/90/180/270；eye-off = eye 换瞳孔加斜线。状态对/反向族绝不画第二张脸——派生是纪律不是技巧。
- **规范是契约、测试是门禁**：spec lint 逐图标断言 IconBase 属性契约 + **几何锁**（渲染 d 必须等于设计 d，改图必挂测试强制 specs 复核）+ 整数网格 + 节点/圆范围 + 文档化光边界常量 + 成对同源。机器查得到的全查，查不到的（成对同源的手工观感）走人工审。
- **克制**：stroke 单一变体（filled 有语义才进）、零运行时依赖、无子路径导出（preserveModules 文件级树摇已够）、不预筑「svg 资产 → 生成组件」管线（源即 SVG 几何，Figma 管线来了是同构后置）。
- **终审是人类的眼睛**：每批次渲染 PNG 交用户肉眼验；机器门禁保证「不坏」，终审保证「好看」。
