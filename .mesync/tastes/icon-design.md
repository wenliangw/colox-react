# 图标设计规范

图标是设计语言「看得到的那张脸」——库必须自己拥有基础图形集（用户定调），SVG 组件源是唯一形态（icon font 死在 stroke 度量上）。规范本身是**契约**，机器门禁是执行。

- **包边界**：第一方基础图标独立包 `@colox/icons`；组件内置态与消费方共用同一源（不是私藏拷贝）；插槽仍收 ReactNode——基础成语用本包、业务图形自备（业务图形是用户自备的 SVG/三方包，库不提供自绘基座）。
- **公共名字自带语义**：导出 = `IconXxx` 前缀命名（IconEye/IconCheck/IconX）——前缀承载语义显性（JSX 现场即知身份）与防碰撞（X/Eye 等高频词与开源图标库、业务命名必撞，前缀让多生态共存零别名）；仅有 per-icon 命名导出（单轨），没有命名空间件/字符串索引/双名出口——语义交给名字、树摇交给结构，两不相害。
- **两个本体造型轴对仗**：`size?: number` + `color?: string` 都是图标一等 prop（不是屈居 style/attr 的隐形通道）——图标两高频造型轴 = 多大（size：px 显式、默认 1em 继承字号，排版系不套 spacing 键）与什么色（color：任意 CSS 色、默认 currentColor 继承宿主）。同类高频轴必须同等待遇，一个升格一个降格就是两把尺子。
- **语境语义归宿主**：状态色（Success/Danger 借）/语境间距是行为层词汇——Message status 设容器 color、图标 currentColor 零配置继承；icons 不译语义键（`color="success"` 不进包，翻译语义键 = 依赖 theme 词表 = 零依赖纪律破）。脱离语境给图标举例性上色 → color prop；语境内的状态色 → 宿主管。
- **契约收在内部**：`IconBase` 不进公共面（内部单点持契约 + 透传通道）；高频动作（取一枚图标）必须零门槛——`<IconEye size={16} />`，不让用户碰 SVG 底材。显式 `style.color` 仍优先于 `color` prop（直接 style 是更低层通道）。
- **度量锚在做换算**：24 viewBox / stroke 1.5 / round cap+join / currentColor / 1em。每一条都有几何理由，不是风格自嗨——1.5@24 在 16px 渲染恰等效 1px（组件边框同频）、currentColor 继承语义色、1em 继承字号（token 体系流经宿主）。
- **圆角挂 token 家族**：直角弯 r=2（radii.xs）、大弧 r=4（radii.sm）——形语言事实与组件共享，不发明新值。
- **整数网格 + [2,22] 光学内容框**：节点全整数（亚像素锐利）、笔画含 bleed 不越内容框（与文字并排行高不打架）。
- **成对同源**：chevron 四向 = 一张 d 旋转 0/90/180/270；eye-off = eye 换瞳孔加斜线。状态对/反向族绝不画第二张脸——派生是纪律不是技巧。
- **规范是契约、测试是门禁**：spec lint 逐图标断言属性契约 + 公共透传（size/color/className/a11y）+ **几何锁**（渲染 d 必须等于设计 d，改图必挂测试强制 specs 复核）+ 整数网格 + 节点/圆范围 + 文档化光边界常量 + 成对同源。机器查得到的全查，查不到的（成对同源的手工观感）走人工审。
- **克制**：stroke 单一变体（filled 有语义才进）、零运行时依赖、无子路径导出（preserveModules 文件级树摇已够）、不预筑「svg 资产 → 生成组件」管线（源即 SVG 几何，Figma 管线来了是同构后置）、**图标清单不预置全量**（按需追加：遇到才加——公共图标是 semver 承诺，为想象需求预画的每一枚都是无用承诺）。
