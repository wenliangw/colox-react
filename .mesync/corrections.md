# 纠错检查库

## 定位

- 这不是错误台账，而是**「行为 → 关联检查清单」**：记录「当改这里的时候，需要检查/同步的哪些地方」。
- 错误本身（时间、经过、症状史）不记录——记录错误的出发点不是复盘，而是**将来相同或类似行为不要漏处理内容**。
- 每条以「**改这些 → 必须检查这些**」为主干；允许一行「为什么」作为锚点，帮助理解检查项存在的理由。
- 归属纪律：这是防漏经验，**不是品味**，不进 `tastes/`（tastes 只收用户对代码的偏好）。

## 索引

### 改名类重构（token 名 / CSS 变量名 / 属性名 / 文件名）

**改这些**：`packages/theme/src/styles/tokens/*.tokens.json` 的定义名、组件 `styles/` 里朝主题变量的引用、SD 配置。

**必须检查**：

1. **消费侧同步替换**：改名后全仓搜引用（grep 新名、旧名双向确认）；右侧 `var(--colox-*)` 引用同样是消费侧，sed 不要只替换左值/一侧。
2. **产物抽检**：CSS 变量断裂对 jsdom 测试、vite 构建、tsc 全部不可见（`var()` 运行时解析、未定义静默判无效）——重建后用 grep 检查 dist：新名存在、旧名计数为 0。
3. **联动重建链**：theme build → demo 资产重编译（`pnpm --filter @colox/preview themes:demo`）→ react build → 三个 dist 抽检。

**为什么**：曾因 token 双连字符回退只替换了局部变量左值、右值 `var(--colox-color-brand-solid--hover)` 挂旧名，全部按钮 hover/active 白掉一块。
