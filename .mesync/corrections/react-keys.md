# React key 语义：换内容必重挂 → key 必须复合唯一

## 词面重挂的 key 取「计数/版本」单字段 → 跨条目同值被复用、动画静默只播第一次

- **改这里**：任何「借 key 变化来重挂子结点/重播动画」的形态（换载荷词面、替换槽、折叠补位、露出的 zoom 词面）。
- **必须检查：**
  - [ ] key 的取值域必须覆盖「会换进这个位置的**不同条目**」——两个条目可以同时持有相同的版本号（pop 补位与到卡 bump 都从 1 开始），裸 `contentVersion` 碰撞时 React 视同同一元素、**复用 DOM 节点**：不重挂、动画不重播，且测试全绿（css class 都在、只是 animation 不会重触发）。
  - [ ] 用复合 key：`id + ':' + version`（或单调递增的槽级计数器）——换条目必换；同条目换载荷靠 version 进位必换。
  - [ ] jsdom 断言动画重播：比较前后两帧关键结点的**节点引用**（`first !== second`）——jsdom 不执行 keyframe，唯一可测的是「重挂了没」。
- **为什么**：消息折叠 pop 连关两张：两张被晋升卡的 contentVersion 都从 0 加到 1——body key 均为 1，React 复用第一张的词面结点，第二张的 zoom 静默缺席；用户浏览器报「zoom 只有第一个被替换的卡片有，后面就都没有了」。key 相等 = React 的「同一元素」承诺，语义上「每次露出都是新词面」时必须保证不同条目键值不同。
