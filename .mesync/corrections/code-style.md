# 组件交付 / 改造前：代码习惯对照清单

- 新组件交付或存量件改造收尾 → 必须逐项对照 `.mesync/tastes/code-style.md` 自查（TimePicker 自查轮被指正则项）：props 三处同序（接口 / 解构 / 调用点，属性 → 方法入参 → 事件回调）、无零语义穿透 wrapper（scrollColumn=moveColumn 式）、同构方法合并为族级单实现（isDisabledHour/Minute/Second → isDisabledOption）、无三目链（三路分支走 guard/查表）、pad/mod 类公共工具集中在 utils 不散落各文件、模块头注释 ≤3 行（禁大论文 docblock）。
- 回填 kebab 命名式新 prop（confirmText 类）到既有接口 → 必须同时检查组件解构处与 hook 调用点是否保持同序（字段序约定是「三处」不是「接口一处」）。
- 新组件交付 → 必须注册 form 的**组件身份映射**：`resolve-empty-value`（空值词档）与 `resolve-control-kind`（布尔判定）。TimePicker 交付时漏挂空词档、静默落到默认 text 词 `''`（功能不坏——编辑会立刻写 canonical；但 store/提交载荷的「未选」呈现 `''` 而非时间域的 `null`，与 DatePicker 漂移）——身份映射是「新叶组件交付检查单」的一员。
- 新组件交付 → 组件文档页（`apps/docs/docs/components/*.mdx`）写好还不够，必须**挂进 `apps/docs/sidebars.ts` 的显式分组**——Docusaurus 侧栏不是 auto-generated，未挂 = 站点导航不可达。TimePicker/form 两页此前的交付漏了侧栏注册（文件在、导航没有），Compact 轮顺带补齐。把「sidebar 注册」写进组件交付检查单。
- 覆写件/缝合件写「覆盖成员自带样式」的规则（圆角、边框、焦点环/阴影、几何）→ 必须检查**特异性足以压过成员的自身类**：成员自己的基类（`.colox-input` 等）是 0,1,0、成员焦点环是 0,2,0（`:focus-within`/`:focus-visible` 挂在自身类上），覆写规则写到 0,3,0（类 + 伪类，如 `:not(:disabled)` 做载体、`:is(族并集)+:not([aria-invalid])` 提到 0,4,0）才与样式表顺序无关——同分平手会按聚合顺序输给后到的成员样式，成员样式「复活」（Compact 首版圆角 bug、首版焦点环 bug：成员环自圈 + 溢出 2px 压到邻居，用户两次目视逮住）。加一条设计判据：**缝合单元的焦点/选中态归组**（组级 `:focus-within` 一环），成员各自的环在组内静默——「组是一个视觉单元」的预期下，状态可视面也应是单点。**焦点环静默了、焦点边框变色也要静默**——环和 border-color 是同一枚「选中态」的两半，只杀一半就会剩「组环 + 成员自身色边」两层选中样式（Compact 被用户第三次逮住）；输入族静息边框 = 全家共享的 muted token 可安全钉住，变体色板（如 Button solid/ghost）永不直升。
- 缝合/覆写件交付或改完 → 过一遍**「成员 × 状态」矩阵**再报完成（Compact 多轮目视逮 bug 的总教训——用户点名「完整诊断一次」后一次漏四个）：①**宽度**——成员自带 `width:100%` 进 flex 组会遇 min-width:auto 地板(定宽组里贴不满/溢出,呈现「不到一半」)——输入族 `flex:1 1 auto; min-width:0`,定宽均分/无宽按内容撑开双语义;②**invalid 归属单元**——组是一个整体:成员 invalid 后**全单元红色**轮廓(`:has` 族级 tint,按钮变体豁免)、焦点环也在 invalid 单元内任意聚焦转红;**不要**只标坏段、不要用 z-order 升高/接缝侧透明这类「成员级手术」(试过,用户明说否决:「仅有一个 invalid input,但 compact 应该是一个整体才对」);**状态信号 key 用根元 class**(`--invalid`/`--disabled` 后缀)**不要用 aria 属性**——家族的 aria 通道(aria-invalid/aria-disabled)挂**内层控件**上、根元只有 cva 类:按 `[aria-invalid]` 查直系子件永不触发(Compact 首版 tint = 半红框,用户逮住),连 `:not([aria-invalid])` 排除也会恒真误伤;③**形状件**——自身设计语言带圆形的成员(Switch 轨道/Slider rails)豁免半径规则,不要被缝 squaring;④**阴影与动效**——静态 elevation 阴影、`:active` 缩放(scale)会在缝上撕裂缝隙,组内静默;⑤**弹层开合与焦点**——成员开弹层走 shell-click 时,不可聚焦的 shell(chevron/图标是 span 或 pointer-events:none 的 svg)在 **mousedown 默认行为**里把焦点 blur 到 body(弹层开在 portal 里、`:focus-within` 看不见)——中间帧会把「选中态」闪灭又复明(Compact 被用户逮住:「border 闪一下,选中样式丢失又恢复」):**非交互区 mousedown `preventDefault` 焦点驻车**(守卫 closest('button, input') 豁免真控件与按钮),click 再原子换手;成员开态在根元挂 `--open` 状态类(Select 先例,DatePicker/TimePicker 补上),组环 `:has(> [class*='--open'])` 认弹层开态 = 单元 engaged。矩阵里的每一项都要问「这个状态会不会画到邻件身上/撕开缝**/这个状态该由成员还是单元说话**」。⑥**继承词走 context 不进 clone**:级联默认值(size/palette 类)用「成员自声 ?? context ?? 硬默认」的回退链,`context` 放在 cdk 供全员消费——缝合件/组合件**禁止 cloneElement 注入**(Compact 红线「成员保持作者原元素」;Form 的注入是控件持有层的既定机制,不复制);组件 destructure 里的硬默认(`size = 'md'`)在引入 context 回退后要改成链末位,否则回退永不可达;「环只替某类成员说话」这类范围收紧时,**静默规则要同步划区**,不然非该族成员会失去自己的 affordance。⑦**双边框重叠拼出的分割线不是设计;分割线本身也别走 border 机制**——「中间线丑」的本质是两边框叠带 + 边角 AA,解法是「单元画框 + 边界坐线」(边框语义从成员让位给单元);且边界线要画成**短浮动条**(伪元素 `inset-block: 25%`),别用 border-inline-start——border 画全高线、与外框焊死(用户:高度该短些,别与 border 相连),还会被 strip 类重置规则(后面的 `border:0`,0,2,0 压 0,1,0)按序清零,导致「分割线整体隐形」(用户:没看到 divide)——任何待渲染的线条都要先跟覆盖它的 reset/strip 规则对一遍特异性账。⑧**cdk 是无域基建,别把域专属契约放进去**——CompactContext 一度放 `src/cdk/`,它 import `../compact/types`:基建朝上依赖组件域(倒挂),且 `@colox/cdk/*` 是未来晋升独立包的命名(combobox/floating/input-control/date/utils 全无域),域专属件混入让包边界失守(用户:「为什么写在 cdk 里,这是不对的」)。域契约归域:`src/compact/compact-context.ts`,消费方相对路径 import(`../compact/compact-context`),依赖边单向(成员 → 缝契约,契约不 import 成员,无环);**相对路径深度按文件真实层级算**——成员在 `src/<name>/` 一层深,是 `../compact/` 不是 `../../compact/`(本轮实踩,写完先 grep 路径核对一遍)。

- 手写事件守卫的 `event.target instanceof` 判定 → **用 `Element` 不要用 `HTMLElement`**:SVG 元素(SVGElement)不是 HTMLElement 的实例,而且图标惯用 `pointer-events: none`(真实浏览器点击落在背景节点上,j sdom 不模拟 pointer-events 会把 svg 直接当成 target)——用 HTMLElement 守卫,target 是 svg 时静默早退(shell-click/mousedown 整个不触发,单测逮住)。
