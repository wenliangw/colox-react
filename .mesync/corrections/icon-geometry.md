# 图标几何（icon geometry）

改动 stroke 图标的几何（新增图标 / 修正路径）时，逐条对照：

- [ ] **直线↔圆弧接点切线连续**：圆弧端点处的切线必须与相接直线同向（或干脆不放圆弧、用纯折线 + round join 收圆角）。切线断裂的拼接头在小尺寸下被 round join 抹平、放大后 stroke 加粗就显形成「线条不直/失真」——前科：chevron 旧几何 `L13 10 A2 2 0 0 1 13 14` 在 45° 臂与水平切线圆弧之间断裂 45°，40px 渲染失真，用户指正后改纯折线 `M9 6 L15 12 L9 18`。
- [ ] **整数网格**：spec lint（test/icon-spec.test.tsx）强制 d/cx/cy/r/transform 的一切数字为整数——精确切线的圆弧端点必然是无理数（如 45° 切线点 (14.41,10.59)），整数网格下要么纯折线、要么验证接点角度差小到不可见。
- [ ] **[2,22] 光学内容框**：所有显式节点（含圆弧端点）与圆的包络必须在框内。
- [ ] **BOUNDS 文档同步**：改几何后重算该 glyph 的 `BOUNDS` 行（含 stroke bleed ±0.75）——旧值只在 [2,22] 软断言层面检查，对不上不会报错，是静默腐化点。
- [ ] **成对同源不动摇**：chevron 四向 / eye-off 派生关系是单几何旋转/替换，改左 / 改右必须经同一源。

为什么锚：用户 2026 放大渲染 IconChevronDown 后指正「线条不是直的」——小尺寸不可见的几何断裂在放大后显形；心法 = 「几何要 zoom-proof：曲率变化只允许在圆角小半径上，臂线保持纯直」。
